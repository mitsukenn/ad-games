# Million March：デザイン・UI・見せ方の工夫

`million_march.html` で効いた工夫のまとめ。ほかの広告ゲーム（迎撃ロードなど）に流用しやすいよう、仕組みと数値も書いておく。

## 1. カメラと画面の見やすさ

- **引きの高いカメラ**：隊列の 14.5 後ろ・高さ 7 から見下ろす（`CAM_BACK`・`CAM_Y`）。描画距離 150。軍勢の規模と、先のゲートや巨人が同時に見える
- **焦点距離を画面の高さに合わせる**：`FOCAL = clamp(300, H*0.92, 700)`。iPad の埋め込み表示など背の低い画面でも、隊列が下にはみ出さない
- **戦闘中は少し引く**：巨人戦はカメラを 1.08 倍後ろへ。巨人の頭と足元の両方を画面に収める
- **パネルは背の低い画面で詰める**：高さ 900px 以下で文字と余白を小さくし、ボタンまで1画面に収める。入りきらないときはパネルだけスクロールできる（`overflow-y:auto`・`touch-action:pan-y`）。ドラッグ操作は `.ov` 上では拾わない

## 2. 手応え・演出（広告ゲームらしい気持ちよさ）

- **兵力の数字を回す**：表示は本当の数に向かって毎フレーム近づける。増えるときはゆっくり、減るときは速く（`tickHud`）。大きく増えたら数字が弾む（`.bump` アニメ）
- **桁の節目を祝う**：1千・1万・10万…を超えたら「1万 突破!」を大きく出し、効果音と振動を入れる
- **大軍の見せ方**：画面に描く兵は 420 人までにして、それを超えたら隊列を縦に伸ばす（`log10(count/420)` に比例）。1万で軍旗、10万で金の旗、100万で王冠の紋入り
- **巨人の登場を予告する**：約 44 手前で、赤黒の警告帯と「WARNING 巨人接近」を出してサイレンを鳴らす。カメラも一瞬前に寄る
- **一撃を予告する**：巨人の足元の輪が、振りかぶりに合わせて広がって光る。叩きつけの瞬間に衝撃波と土煙の画像を出し、画面を揺らす
- **ステージの告知**：毎ステージ「STAGE n」。難しさが変わるステージ5だけ赤字で「ここからが本番」と出し、専用のファンファーレを鳴らす
- **文字は背景に負けないよう下地を敷く**：告知や警告の小さい文字には、半透明の暗い帯と金の細い枠を付ける（空が明るい背景絵でも読める）

## 3. 画像素材の使い方

- **画像がないときは今の描画に戻す**：`SpriteKit.foot/center/footW` が false を返したら、従来の Canvas 描画をそのまま使う
- **巨人のポーズごとに高さを補正する**：ポーズによって絵の高さが違う（叩きつけはかがむ）ので、`見えている高さ ÷ 立ちポーズの高さ` を掛けて体の大きさをそろえる
- **ポーズの切り替え**：戦闘外は立ち。戦闘中は一撃の直後から 0.14 まで叩きつけ、0.42 まで立ち、残りを振りかぶりにする
- **回転刃**：刃と支柱が1枚の絵なので、丸ごと回すと支柱まで回ってしまう。横方向に `|cos|` で縮めて、縦軸まわりに回っているように見せる
- **武器ゲートの中身**：「次に手に入る武器」の画像を出す（今の武器 +1）。何がもらえるかが一目で分かる
- **形が合わない素材は使わない**：ゲート枠の画像は正方形に近く、横長のゲートに合わせると潰れるので見送った

## 4. 難易度の見せ方

- **序盤は無敵感**：ステージ1〜4は「毎回損なゲートを選んでも勝てる」前提で敵の数を決め、さらに 55〜70% に弱める。ステージ1・2は減るゲートを出さない。刃はステージ4から
- **自動プレイで数字を測ってから調整する**：`update(dt)` を同期ループで回し、上手い人・普通の人・下手な人の3タイプで各ステージのクリア率を測った
- **ご褒美の区切り**：3ステージごとにボーナスステージ（赤ゲート・敵なし、宝箱を拾うだけ）。次のステージの敵はそのときの兵力に合わせるので、増えすぎても難しさは崩れない

## 5. 音

- **行進曲のBGM**：Web Audio で4小節ループを作る。スネアは「タッタ・タン」、ベースは「ブン・チャッ」。戦闘中はテンポ 132 → 150 に上げ、太鼓を細かくする
- **負けの音を寂しくしない**：下がっていく音をやめて、ずっこけ系の「ぽよよ〜ん」にした
- **BGM と効果音は別の音量**：GainNode を2本に分け、設定画面のスライダーで個別に変えられる。設定は localStorage に保存

## 6. 遊びやすさ

- **一時停止**：右上のボタン・P・Esc。アプリを切り替えたときも自動で止める（`visibilitychange`）
- **続きから**：ステージの開始時に自動保存し、タイトルに「続きから（Stage n）」を出す
- **振動**：まだ一度も画面に触れていない間は呼ばない（Chrome が警告を出すため）。iPhone の Safari は非対応
