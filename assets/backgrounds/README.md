`../../background_catalog.html` でレベルを切り替えて確認できます。縦画面ボタンはスマホ相当の中央トリミングを表示します。画像は横長なので、縦画面では左右の建築が一部見切れます。横ループ用のシームレス画像ではありません。

既存ゲームは変更せず、画像と切り替え用ヘルパーを準備しています。2レベルごとの割り当ては提案で、変更可能です。

## 組み込み

ゲーム本体のスクリプトより前に次を読み込みます。

```html
<script src="assets/backgrounds/backgrounds.js"></script>
```

既存の `drawSky()` 内で呼び出してください。

```js
if (StageBackgrounds.draw(ctx, stage, W, H)) return;
// 読み込み前や失敗時は既存の背景描画を続ける
```

画像は画面全体を覆います。後から `drawGround()` が地面を塗る構成では背景の下半分が隠れるので、ゲームに合わせて地面描画を調整してください。道路・兵士・UIは背景より後に描きます。ヘルパーは現在の背景と次の背景を先読みします。11以上は天空、1未満や不正値は序盤の背景を返します。リセット時もstageから背景を選び直します。

## 確認

5枚の画像を目視し、テーマ・構図・文字やUIがないことを確認。寸法、ファイル参照、スクリプト構文、レベルの境界選択を検証。ゲーム内の視認性・描画負荷と一覧のブラウザ実表示は未検証です。
