# レベル別の兵士・通り抜けゲート

2026-09-21、Built-in ImageGenで制作。採用画像は soldiers.png と gates.png の2枚、各1254×1254pxの透過PNGです。兵士10ポーズ、ゲート6種類をシート内に収録しています。個別PNGではありません。

| レベル | 兵士（背面・走り2コマ） | ゲート |
|---|---|---|
| 1–2 | 青い服の歩兵 | 苔むした遺跡の門 |
| 3–4 | 銅鎧・砂漠のスカーフ | 黄金色の砂岩の門 |
| 5–6 | 銀鎧・毛皮の襟 | 氷雪の門 |
| 7–8 | 黒い重装鎧・青マント | 溶岩色の火山の門 |
| 9 | 白銀と金の聖騎士 | 天空の門 |
| 10 | 白銀と金の聖騎士 | 紫水晶付きの最終決戦の門 |

兵士は全段階で青い味方と分かる配色、武器を後から重ねるため空の手です。敵兵は今回追加していません。ゲートは正面向き、左右2つの開口部、地面をふさぐ敷居なし。開口部と外周が透明です。数字・演算・色付きの選択パネルはゲーム側で描いてください。

`../../level_asset_catalog.html` で背景・兵士・ゲートの組み合わせをレベルごとに確認できます。道と「+20」「×2」は説明用の描画です。実際の通過判定はなく、ゲーム本体は変更していません。

## 読み込み例

```html
<script src="assets/level-units/level-assets.js"></script>
```

```js
const theme = LevelAssets.forLevel(stage);
const frame = Math.floor(time * 5) % 2; // timeは秒
LevelAssets.draw(ctx, theme.soldiers[frame], x, y, 30, 55);
LevelAssets.draw(ctx, theme.gate, gateX, gateY, 360, 240);
```

`draw` は読み込み前・失敗時にfalseを返します。既存のCanvas描画へフォールバックできます。矩形情報は `LevelAssets.catalog.sprites` および manifest.json を参照してください。兵士は足元の余白差を減らすよう上下のセルの切り出し位置を調整しています。

## 確認事項

採用画像を目視確認し、実寸・透過・矩形境界・レベル割り当て・JavaScript構文を検証。元の生成案で背景色が残ったものは不採用です。生成画像なのでフレーム間の服の形・体格にはわずかな差があり、一部スカーフがセル端に近いため、最終実装時は足元・握り位置・隣セルの混入・縮小時の見え方を調整してください。ブラウザ上の実表示とゲーム内の動作は未検証です。
